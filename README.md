# GPU 遮挡剔除（gpu-occlusion-culling）

## 题面

开放世界加遮挡剔除后，远景物件一闪一闪：AABB 投影跳过近平面裁剪，相机后方物体仍进入可见列表；深度金字塔层级向下取整，宽高跨层时采到更细层而漏判遮挡；深度比较用 `>` 而不是 `>=`，与遮挡面共面的物体被剔除；保守模式也把 unknown 丢弃，转身时出现闪烁；排序使用不稳定的 `sort`，同距离物体顺序逐帧变化；查询矩形不去重，深度回读次数翻倍；早深度通过率按对象数而不是像素数统计；批量剔除共用可见列表，帧与帧结果相互累积；空 AABB 不做校验，投影产生 NaN；金字塔层数不足时不回退，直接越界读取。cull/occlusion.py 是核心，tests/test_occlusion.py 15个红。要修的是：投影先做近平面裁剪并校验 AABB；层级选择改为向上取整并在层数不足时钳到最后一级；深度比较改为严格小于（等深不剔除）；保守模式保留 unknown 并让未知对象继续参与可见；使用稳定排序保持同距离顺序；查询矩形按重叠合并去重；早深度通过率按像素统计；每帧使用独立结果列表；批量校验失败时整体回滚。

## 运行方式

在仓库根目录执行：

```bash
python -m pytest tests -q
```

初始状态必须恰好是 `15 failed`，不能出现 collection/import/syntax error。修复 `cull/occlusion.py` 后，同一命令应全部通过。
